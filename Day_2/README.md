# Day 2: Data Extraction and Spark Setup

**1. SEC API Data Extraction:**
- Viết script Python (`extract_sec_api.py`) kết nối thành công với sec-api.io.
- Trích xuất thành công và lưu trữ thông tin của 14,867 công ty chứng khoán vào file `raw_companies.json`.

**2. Apache Spark Installation:**
- Tải, giải nén và thiết lập thành công Apache Spark (version 3.4.1) trên hệ thống.
- Cấu hình thành công các biến môi trường (`SPARK_HOME`) trong file `~/.bashrc`.

**3. Repository Organization:**
- Tổ chức lại cấu trúc dự án thành các thư mục riêng biệt `Day_1` và `Day_2` để dễ dàng quản lý theo tiến độ dự án.
